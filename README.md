## 🚀 Progetti

### [Web Application Project](https://github.com/Jeck-VV/Web-Application-Project)
Gioco puzzle single-player ispirato a *Race the Rails*: pianifica a memoria un percorso della metropolitana in 90 secondi e affronta eventi casuali. Realizzato con React, Node.js/Express, SQLite e Passport.js, include una classifica globale.

### [Real-Time Vehicle Tracker](https://github.com/Jeck-VV/Real-Time_Vehicle_Tracker)
Sistema client-server in Rust per il tracciamento in tempo reale di una flotta: aggiornamenti di posizione, simulazione dei movimenti, analisi di percorsi e velocità e messaggistica.

### [Participium — Software Engineering](https://github.com/Jeck-VV/Participium_software_engineering)
Piattaforma open source per la partecipazione civica: consente di segnalare e monitorare problemi urbani tramite mappa interattiva, gestione trasparente delle segnalazioni, notifiche e statistiche.
